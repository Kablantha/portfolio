Scribus

Scribus is free and open-source software (FOSS) designed as an alternative to Adobe InDesign. It is primarily used for document creation, including the preparation of documents for professional printing. Scribus is available for all major operating systems; I used it on Windows and Linux.

I chose to learn this program because it is an open-source alternative to an industry-standard. My training for this program consisted of multiple hands-on projects. Roadblocks and barriers were addressed through community forums, videos, and other resources to assist with the specific needs of the project. My understanding of this software not only helps me use it better, but also helps me with the use of similar programs for layout and design.

Board Game Manual

STATUS: FINAL · FILE: SCRIBUS_MANUAL.SLA

This document is the game manual for the boardgame "Risk and Re-Entry." It was created using art assets from other students in Intro to Game Design, but was designed entirely by me. It taught me how to extend text into multiple boxes, how to align boxes with each other, and how to create a border.

Game Pitch Packet

STATUS: FINAL · FILE: SCRIBUS_PITCH.SLA

This document is a theoretical game pitch packet for a game called Rainbow Brigade. It taught me about complex layering of semi-transparent layers, precise positioning of elements in relation to others, and a fully-fleshed style guide for ease of recreation. This is the most complex document I have designed in Scribus to date.
